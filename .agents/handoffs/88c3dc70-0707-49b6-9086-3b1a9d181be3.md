## Key paths
- **App glue:**
  - `Sources/Pankapture/CaptureCoordinator.swift` routes every flow: output, history, thumbnails, pins, editor, recordings.
  - `RecordingCoordinator.swift` and `ScrollingCaptureController.swift` hold the recording and scrolling-capture glue.
- **Overlay:** `Sources/Overlay/` (`OverlayView`, `OverlayController`, `AnnotationInteraction`, `ImageEditorWindow`).
- **Scripted QA tool:** `/tmp/pk-tools/mouse` (synthetic mouse and keys).
  - `mouse overlay` prints how many overlay windows are open. Never click unless it prints ≥1.
- **URL triggers:**
  - `open "pankapture://capture/area?rect=x,y,w,h"` opens the overlay with a preselected area.
  - Fullscreen via URL needs the `general.allowsURLAutomation` default set to true.
- **Gotchas:**
  - `git merge` is denied by permissions; integrate branches with `git checkout <branch> -- <paths>` plus manual edits.
  - The GateGuard hook asks for facts before first-time file writes and "destructive" commands.
  - zsh shadows `log`; use `/usr/bin/log`.
  - SwiftPM resources don't work inside the hand-assembled `.app`.
